## Cómo abrir en VS Code
1. Extrae esta carpeta con WinRAR
2. Abre VS Code → File → Open Folder → selecciona AF-Corporate
3. Abre index.html en el navegador para ver el resultado

## Deploy en GitHub Pages
1. Sube index.html a tu repositorio GitHub
2. Settings → Pages → Branch: main → Save
   Sitio: https://andresfelipe00525-code.github.io/AF-Corporate
